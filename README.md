# صفارة (Soffara) ⚽🟨

تطبيق شلة الكورة: حجز ملاعب + تصويت مين جاي + دردشة جماعية.
شغّال زي أي تطبيق حقيقي (PWA) — تقدر تفتحه من المتصفح أو تضيفه لشاشة الموبايل الرئيسية زي أي أبليكيشن.

المرة اللي فاتت كان مبني على Supabase (لازم تكتب SQL). دلوقتي بقى مبني على **Firebase** —
مفيش أي كود SQL خالص، كله دوس دوس ونسخ ولصق.

## 1) جهّز قاعدة البيانات (Firebase) — 3 دقايق، من غير أي كود

1. روح https://console.firebase.google.com وسجل بحساب Google بتاعك.
2. دوس **"Add project" / إضافة مشروع** واكتب اسم زي `soffara` وكمّل الخطوات (تقدر تقفل Google Analytics، مش لازم).
3. من القايمة الجانبية اليسرى: **Build → Firestore Database**.
4. دوس **Create database** → اختار **"Start in test mode"** → اختار أي location قريب منك → **Enable**.
   - خلاص، الداتابيز جاهزة. مفيش أي جدول أو كود تكتبه.
5. دلوقتي هنوصّل التطبيق بيها: من القايمة الجانبية دوس على أيقونة الترس ⚙️ جنب "Project Overview" → **Project settings**.
6. انزل لتحت لحد قسم **"Your apps"** → دوس على أيقونة **</>** (Web app) → اكتب اسم (مثلاً `soffara-web`) → **Register app**.
7. هيظهرلك بلوك كود اسمه `firebaseConfig` فيه أرقام وحروف كتير — **انسخه كله**.

## 2) وصّل التطبيق بـ Firebase

افتح ملف `config.js` والصق البلوك اللي نسخته مكان الـ placeholders:

```js
window.SOFFARA_CONFIG = {
  firebaseConfig: {
    apiKey: "...",
    authDomain: "...",
    projectId: "...",
    storageBucket: "...",
    messagingSenderId: "...",
    appId: "...",
  },
  ADMIN_CODE: "M3ss!10B@rca",
  APP_NAME: "صفارة",
};
```

> **كود الأدمن** هو نفسه اللي طلبته (`M3ss!10B@rca`). أي حد يكتبه في شاشة الإعدادات هيبقا أدمن ويقدر يحجز/يمسح حجوزات. غيّره في أي وقت من نفس الملف.

> ملحوظة: "test mode" بتخلي أي حد معاه اللينك يقرا/يكتب لمدة 30 يوم بس، وبعدين تحتاج تحدّث الصلاحيات. الخطوات في ملف `firestore.rules` — نسخ ولصق برضه، مفيش SQL.

## خطوة إضافية: تفعيل "تسجيل الدخول بجوجل" (اختياري)

لو عايز خيار "سجّل بحساب جوجل" يشتغل، محتاج تفعّله مرة واحدة من نفس مشروع Firebase:

1. من القايمة الجانبية في Firebase Console: **Build → Authentication**.
2. دوس **Get started**.
3. من قايمة "Sign-in method"، دوس على **Google** → فعّلها (Enable) → اختار إيميل للدعم → **Save**.
4. لسه في نفس صفحة Authentication، روح تبويب **Settings → Authorized domains**.
5. دوس **Add domain** وضيف الدومين بتاع موقعك (مثلاً `alielref9-droid.github.io`).

من غير الخطوة دي، زرار "سجّل بحساب جوجل" هيدي رسالة خطأ، لكن **باقي التطبيق هيفضل شغال عادي تماماً** حتى لو الخطوة دي متعملتش.

## 3) ارفع التطبيق أونلاين (مجاني)

أسهل طريقة: **Netlify Drop**
1. روح https://app.netlify.com/drop
2. اسحب فولدر `soffara` كامل (بكل ملفاته) وارميه في الصفحة.
3. هياخدك لينك زي `https://soffara-xxxx.netlify.app` — ده لينك التطبيق، ابعته للشلة.

بدائل تانية: Vercel، GitHub Pages، أو Firebase Hosting نفسه — نفس الفكرة، ترفع الفولدر وخلاص.

## 4) كل واحد في الشلة يستخدمه إزاي

- يفتح اللينك، يسجل اسمه وصورته (اختياري) ورقمه/واتسابه.
- من المتصفح (Chrome/Safari) يقدر يضغط **"إضافة إلى الشاشة الرئيسية"** فيبقا شكله زي أبليكيشن عادي على الموبايل.
- النقطة اللي فوق (خضرا/حمرا) بتقول لو النت متصل ولا لأ.
- الأدمن (اللي معاه الكود) بس هو اللي يقدر يحجز ملاعب جديدة أو يمسحها. أي حد يدخل الكود في الإعدادات هيبقا أدمن.

## ملاحظات مهمة

- الأمان هنا بسيط ومناسب لشلة صحاب مقفولة: مفيش تسجيل دخول (باسورد لكل شخص)، والحماية الحقيقية إنك متشاركش اللينك برا الشلة.
- التطبيق بيكاش الواجهة (الشكل العام) عشان يفتح حتى من غير نت، لكن البيانات نفسها (حجوزات جديدة/رسايل) محتاجة نت عشان توصل وتتحدث، وده اللي بتوضحه النقطة الحمرا.
- عايز تطور حاجة تانية بعدين (تنبيهات، صور في الدردشة، ...)، تعالى قولي.
